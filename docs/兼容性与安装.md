# 兼容性与安装说明

## 安装顺序

1. 在 KernelSU 中停用旧版 Encore、独立 fas-rs、Pixel Global Game Uclamp 以及其他温控覆盖模块。
2. 安装整合包并按安装提示选择温控模式，然后重启。
3. 确认 WebUI 显示服务运行，桌面状态下七项请求为零。
4. 进入游戏后观察请求，退出后确认请求和系统帧率策略恢复；温控状态可检查 `PGT_CHECK=pass`。

## Pixel 10 全系兼容性

- 模块没有型号、设备代号或 `mustang` 白名单；`encore_pixel_cp41` 仅是历史模块 ID 和配置目录名。
- 安装门槛是 arm64、Android 17 SDK 37，以及运行时可写的 CPU/GPU/DSU/IRM 频率接口。
- 温控后端按当前系统指纹重新发现唯一的 Thermal JSON，并校验传感器和冷却设备；无法匹配时只隔离温控 overlay，基础调度仍可运行。
- 当前实机验证为 Pixel 10 Pro XL。Pixel 10、10 Pro、10 Pro Fold 等其他变体应逐台确认启动日志和 WebUI 状态后再长期使用。

## 跨 QPR 行为

- 设备、SDK 和频率预检通过：基础调度继续运行。
- `libgui.so` ELF 符号解析失败：FAS 帧探针关闭，Encore 基础调度继续运行。
- Thermal JSON 没有唯一结构匹配：温控模块隔离，不覆盖系统文件。
- 目标频率不存在：温控模块隔离，避免写入无效频率。
- 系统完整指纹变化：集成温控后端重新建立 stock 缓存；缓存或原子覆盖失败时自动禁用，避免沿用旧 QPR 配置。

## 回滚

在 KernelSU 中停用模块并重启。调度器退出时会恢复本模块持有的投票和帧率策略；温控模块只在成功生成并校验游戏配置后挂载覆盖文件。
