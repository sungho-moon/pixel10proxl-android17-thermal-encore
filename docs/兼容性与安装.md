# 兼容性与安装说明

## 安装顺序

1. 在 KernelSU 中停用旧版 Encore、独立 fas-rs、Pixel Global Game Uclamp 以及其他温控覆盖模块。
2. 安装 Encore 调度包并重启。
3. 确认 WebUI 显示服务运行，桌面状态下七项请求为零。
4. 安装自动温控 v1.6.1 并重启，再检查 `PGT_CHECK=pass`、`enabled=true` 且没有 `blocked-reason`。
5. 进入游戏后观察请求，退出后确认请求和系统帧率策略恢复。

## 跨 QPR 行为

- 设备、SDK 和频率预检通过：基础调度继续运行。
- `libgui.so` 哈希未知：FAS 帧探针关闭，Encore 基础调度继续运行。
- Thermal JSON 没有唯一结构匹配：温控模块隔离，不覆盖系统文件。
- 目标频率不存在：温控模块隔离，避免写入无效频率。
- 系统完整指纹变化：v1.6.1 重新建立 stock 缓存；缓存或原子覆盖失败时自动禁用，避免沿用旧 QPR 配置。

## 回滚

在 KernelSU 中停用模块并重启。调度器退出时会恢复本模块持有的投票和帧率策略；温控模块只在成功生成并校验游戏配置后挂载覆盖文件。
